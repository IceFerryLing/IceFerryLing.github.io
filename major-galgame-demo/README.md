# 哈工深 25届专业选择 Galgame Demo

这是一个围绕“哈工深 25届工科试验班：计算机与信息类专业选择”制作的静态网页 Galgame Demo。玩家可以在五位代表不同专业方向的角色之间进行选择，通过对话和实验室事件了解专业特点，并获得对应的专业倾向结局。

## 运行方式

直接用浏览器打开 `index.html` 即可运行，不需要安装依赖或启动服务器。

## 项目结构

```text
major-galgame-demo/
├─ index.html          页面结构与角色入口
├─ styles.css          场景、角色、对话框和响应式样式
├─ script.js           通用渲染、小游戏引擎、选择逻辑、存档逻辑
├─ characters/         五位角色的独立资料文件夹
│  ├─ cs/profile.js    洛泠资料、剧情、小游戏配置
│  ├─ ee/profile.js    栖禾资料、剧情、小游戏配置
│  ├─ auto/profile.js  青岚资料、剧情、小游戏配置
│  ├─ ic/profile.js    微澜资料、剧情、小游戏配置
│  └─ comm/profile.js  星遥资料、剧情、小游戏配置
├─ png/                当前使用的 PNG 人物图像
└─ assets/characters/  旧版 SVG 角色资源
```

## 已实现功能

- 五个专业分支：计算机、电气、自动化、集成电路、通信工程
- 使用 PNG 人物图像作为角色立绘
- 选中角色后，该角色会放大并占据主要视觉位置
- 每位角色拥有身份背景、性格特色、关键词和个人目标档案
- 五位角色资料、对话分支、小游戏配置分别放在 `characters/*/profile.js`，便于单独修改
- `script.js` 会自动汇总 `window.characterData` 中的角色模块，主脚本只保留通用玩法逻辑
- 每个专业拥有“初选介绍 -> 理论对谈/角色小游戏 -> 实验室事件 -> 方向确认 -> 多方向结局”的剧情流程
- 每位角色增加了专业理论讨论选项，可进一步了解相关知识框架
- 每个专业至少拥有两个结局倾向，玩家可在实验室事件后选择不同发展方向
- 每条角色线加入更青春恋爱向的对话氛围，直线流程不少于 5 轮对话
- 五个角色小游戏：
  - 洛泠：输入 `HIT` 的 ASCII 二进制编码，启动导览 AI
  - 栖禾：平衡光伏、电池与电网供给
  - 青岚：操控巡检机器人避障到达目标
  - 微澜：在版图网格中铺设金属线，绕过 IP 宏单元接通 PAD 与 CORE
  - 星遥：选择稳定的无线链路配置
- 打字机式对话展示
- 理性、热情、协作三项倾向数值
- 结局页会生成专业倾向画像：
  - 基于理性、热情、协作展示雷达图
  - 生成“系统型、创造型、协作型、底层型、探索型”等倾向标签
  - 展示交叉探索 Top 3 和隐藏交叉结局解锁提示
- 本地 `SAVE` / `LOAD` 存档
- `CONFIG` 设置：文字速度、背景动效开关
- 顶部“图鉴”入口：
  - “专业图鉴”展示五个专业的定位、核心课程、能力树、典型去向、适合人群和学习建议
  - “知识卡片”展示各专业关键概念，并可按专业或收藏筛选
  - 知识卡片会随剧情节点永久解锁，并展示解锁、收藏、测验进度
  - 每张已解锁知识卡都支持收藏和三选一测验，收藏与测验结果保存在本地
  - 集齐某专业知识卡后，可解锁该角色的特别对话
  - 完成某专业全部知识卡测验后，会生成带细分能力评分的“专业理解报告”
  - 收藏知识卡可逐级解锁图鉴称号和隐藏建议，称号会显示在结局页和存档提示中
  - 解锁全部知识卡并通过全部测验后，可解锁最终隐藏剧情“全域图鉴”；收藏全收集则作为图鉴称号奖励
  - 答错的知识卡会进入错题本，再次答对后移出，并提升理解值
  - 知识漏洞地图会按专业整理错题，并可直接进入对应角色辅导剧情
  - 图鉴内可直接跳转到对应角色剧情线
- 顶部“联合”入口：
  - 完成相关专业关键节点后解锁跨专业联合事件
  - 计科 + 通信：智能导览网络
  - 自动化 + 电气：自主能源巡检
  - 集成电路 + 计科：AI 加速芯片方案
  - 计科 + 电气：AI 能源调度
  - 计科 + 自动化：自主导航升级
  - 电气 + 集成电路：智能功率模块
  - 电气 + 通信：应急通信供能
  - 自动化 + 集成电路：实时控制芯片
  - 自动化 + 通信：远程无人车联调
  - 集成电路 + 通信：低功耗基带模块
  - 联合事件完成后会记录隐藏交叉学科倾向，并在联合面板显示 DONE / 已完成进度
  - 其中计科 + 通信、自动化 + 电气、集成电路 + 计科、集成电路 + 通信已升级为轻量卡牌式联合小游戏，需要在多项工程指标之间做权衡
- 隐藏结局：交叉学科路线
  - 当至少三个专业探索较均衡、理解值达标，并完成至少一个跨专业事件后，在结局页解锁
  - 可进入“智能系统工程师 / 具身智能研究员 / 天地一体智能网络 / AI 芯片系统设计”等复合方向画像
- 顶部“进度”入口：
  - 展示成就系统：第一次完成小游戏、集齐专业知识卡、完成全部跨专业事件、解锁交叉隐藏结局、清空错题本
  - 展示角色信赖度，信赖达到阈值后可进入对应角色后日谈
  - 根据路线、知识卡、错题本、雷达图和跨专业事件生成专业推荐报告
  - 提供多周目继承入口：保留图鉴、知识卡、错题、收藏、信赖和已看结局，重置课程周与临时倾向
- 顶部“探索”入口：
  - 提供 7 天专业选择日历，每天上午/下午/晚上都有可选择行动
  - 课程周行动分为上课、实验、社团、自习、休息、找角色请教，会影响疲劳、理解、压力、信赖和犹豫值
  - 提供校园地图探索：实验室、图书馆、屋顶、创新工坊、宿舍楼、讲座厅
  - 提供项目制任务：AI 导览组、机器人队、芯片工坊、低碳校园组、无线联调组
  - 日历、地图和项目任务会记录完成状态，并可跳转到对应剧情
- 顶部“辩论”入口：
  - 提供“校园无人车稳定运行”专业选择辩论题
  - 五位角色会分别从路径规划、控制闭环、通信链路、供能安全和边缘芯片提出观点
  - 玩家选择支持、补充或整合某个观点后，会影响隐藏思维标签、三项倾向、信赖和犹豫值
- 移动端基础响应式布局

## 玩法说明

1. 进入页面后，从五位角色中选择一个感兴趣的专业方向。
2. 被选中的角色会成为画面主视觉，并展开该专业的介绍剧情。
3. 阅读人物档案，可选择理论对谈或直接进入该角色对应的专业小游戏。
4. 完成小游戏后继续实验室事件，了解该专业的学习和应用场景。
5. 在实验室事件后进入方向确认对话，再选择不同发展方向进入对应专业倾向结局。
6. 点击顶部“图鉴”可随时查阅专业信息、入门建议、训练路线、避坑提醒与知识卡片；进入角色线、理论对谈或实验事件会解锁对应知识卡。
7. 点击顶部“联合”可查看跨专业事件解锁与完成进度，完成两条相关路线后进入联合剧情；部分联合事件会进入卡牌式权衡小游戏，完成后解锁对应交叉倾向。
8. 点击顶部“进度”可查看成就、角色信赖、后日谈和专业推荐报告。
9. 点击顶部“探索”可进入 7 天课程周、校园地图和项目制任务；课程周每天有上午、下午、晚上三个行动槽。
10. 点击顶部“辩论”可进入专业选择辩论赛，通过发言选择影响隐藏工作方式标签。
11. 可以通过 `SAVE` 保存当前进度，通过 `LOAD` 读取存档。

## 可扩展方向

- 增加角色表情差分、动作差分和剧情 CG
- 加入 BGM、按钮音效和环境音
- 为每个专业增加更多中途选择和多结局
- 根据理性、热情、协作数值生成综合推荐结局
- 增加新生视角的校园地图探索玩法
- 给知识卡片增加错题回顾和全收集奖励

## 玩法新建议

后续扩展可以围绕一个核心目标展开：不要只问玩家“喜欢哪个专业”，而是通过玩家在剧情、知识卡、小游戏和探索模式中的选择，反推出“玩家习惯怎样理解世界”。这样能让专业推荐更像一次真实试错，而不是简单的分数结算。

### 1. 专业人格悖论系统

在现有理性、热情、协作三项数值之外，增加隐藏的“思维方式标签”。当玩家的选择与表面专业倾向出现矛盾时，结局报告不直接给出单一专业，而是指出玩家真正被吸引的工作方式。

示例：

- 玩家一直选择计科角色，但在自动化、通信事件中表现出高兴趣：推荐“具身智能 / 智能机器人 / 边缘 AI”。
- 玩家喜欢 AI 剧情，但更关注芯片功耗和部署效率：推荐“AI 芯片系统设计”。
- 玩家频繁选择跨专业事件：推荐“智能系统工程师 / 复合型工程方向”。

可新增隐藏标签：

- 抽象建模型：喜欢算法、系统、复杂问题拆解。
- 现实闭环型：喜欢设备、控制、能源和真实环境反馈。
- 连接协作型：喜欢通信、网络、平台和多人协同。
- 底层效率型：喜欢芯片、系统性能、功耗和可靠性。
- 交叉整合型：喜欢把多个专业拼成一个完整系统。

### 2. 后悔值与转专业模拟

专业选择最真实的情绪往往不是“选对了”，而是“我会不会后悔”。可以新增“犹豫值 / 后悔值”，记录玩家在选择过程中的摇摆程度。

可触发行为：

- 频繁回到选择界面：犹豫值上升。
- 只玩小游戏、不看理论：热情高，理解值偏低。
- 只探索一个角色：专注值高，视野宽度偏低。
- 均衡探索多个专业：后悔值下降，但决策时间变长。

结局报告可从“你适合某专业”升级为：

> 你对计算机方向有强兴趣，但对自动化场景仍有未完成探索。建议以计算机为主线，同时保留机器人、智能系统方向作为交叉出口。

### 3. 双人联合小游戏

当前跨专业事件已经有完整文本和解锁逻辑，后续可以把部分联合事件升级成真正的小游戏，让跨专业不只是剧情概念，而是系统权衡。

推荐示例：

- 计科 + 通信：路径规划时同时考虑距离、信号强度、拥塞度和延迟。
- 自动化 + 电气：机器人巡检时同时管理电量、路线、负载风险和安全边界。
- 集成电路 + 计科：为 AI 模型选择精度、延迟、功耗之间的部署方案。
- 通信 + 集成电路：设计低功耗基带模块，在误码率、吞吐量和芯片面积之间取平衡。

可采用轻量卡牌式决策：

```text
选择：提高发射功率
结果：链路稳定 +2，功耗 +2，芯片温度 +1
```

### 4. 专业选择辩论赛

新增“导师 / 学长学姐辩论”模式，让五个角色围绕同一个真实工程问题给出不同专业视角。玩家需要选择支持、补充或反驳某个角色。

示例题目：如何让校园无人车稳定运行？

- 计科：路径规划与调度算法。
- 自动化：控制闭环与传感融合。
- 通信：低延迟链路与抗干扰。
- 电气：供能、电池与安全。
- 集成电路：边缘计算芯片与实时性。

玩家的发言选择会影响隐藏标签和推荐报告。例如总是追问“谁负责供能”，说明玩家可能更关注系统可靠性；总是追问“延迟怎么算”，说明玩家可能更关注通信或实时控制。

### 5. 真实课程周压力模拟

现有“7 天专业选择日历”可以进一步扩展为课程周模拟。每天设置上午、下午、晚上三个时间槽，玩家在有限时间中安排学习、实验、社团、休息和角色交流。

行动类型：

- 上课：提升理论理解，少量增加疲劳。
- 实验：提升专业实践值，可能解锁小游戏。
- 社团：提升角色信赖和项目进度。
- 自习：降低错题率，提升知识卡测验成功率。
- 休息：降低疲劳，可能错过限时事件。
- 找角色请教：提升对应角色信赖，触发辅导剧情。

可新增状态：

- 疲劳值：过高时测验更容易失败，剧情中角色会提醒玩家休息。
- 专注值：连续选择同一专业行动会提升，但跨专业视野下降。
- 决策压力：临近第 7 天时上升，影响结局文本。

### 6. 知识漏洞地图

现有错题本可以升级为“知识漏洞地图”。系统不只记录答错了哪张卡，还分析玩家在哪类概念上薄弱。

示例：

```text
通信方向漏洞：
- 调制编码：薄弱
- 信道噪声：薄弱
- 网络协议：基本理解
```

然后根据漏洞触发角色辅导事件：

- 星遥发现玩家总混淆“带宽”和“速率”，带玩家去屋顶做链路测试。
- 微澜发现玩家不理解“时序约束”，邀请玩家旁听一次版图 review。
- 栖禾发现玩家忽略安全边界，安排一次低压实验台检查。

这样错题本不只是惩罚，而是新的剧情入口。

### 7. 工作方式契合度

角色信赖度可以进一步拆成“角色好感”和“工作方式契合度”。角色不只是喜欢玩家，而是判断玩家是否适合她代表的专业工作方式。

示例：

- 洛泠重视边界条件、复现能力和问题定义。
- 栖禾重视安全、稳定、可靠供能。
- 青岚重视调试耐心、控制闭环和现场反馈。
- 微澜重视约束意识、细节耐心和底层效率。
- 星遥重视可靠连接、协作意识和抗干扰思维。

当契合度高时，后日谈可以变成“共同完成一个真实项目”的版本；当好感高但契合度低时，则可以出现更温柔但现实的建议：这个专业很吸引你，但你可能需要先补足某种工作习惯。

### 8. 多周目继承

当前项目已有本地存档、图鉴、知识卡和隐藏结局，很适合加入多周目结构。

推荐设计：

- 第一周目：凭直觉选择角色和专业。
- 第二周目：继承知识卡、错题本、图鉴称号，开放更深层理论对谈。
- 第三周目：解锁全员联合项目或毕业设计路线。

多周目可以出现特殊文本：

> 你已经知道这个选择不会只通向一个答案，所以这一次，你问的问题更具体了。

### 推荐优先级

如果按开发成本和玩法辨识度排序，建议优先实现：

1. 专业人格悖论系统：主要扩展结局报告和隐藏标签，成本低，主题贴合度最高。
2. 双人联合小游戏：能显著强化“跨专业事件”的可玩性和记忆点。
3. 真实课程周压力模拟：把现有探索模式升级成核心循环，适合继续扩成完整游戏。
4. 知识漏洞地图：复用现有知识卡和错题本，能让学习反馈更有温度。
5. 多周目继承：适合在内容量进一步增加后加入，增强重复游玩价值。
